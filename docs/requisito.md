# Desafio técnico: loja B2B

Construa um Ecommerce **B2B**: os clientes são empresas que fazem login para comprar, e cada
cliente pode ter um preço diferente.

A loja deve ter:

- home;
- busca de produtos;
- detalhe do produto;
- carrinho;
- checkout;
- envio do pedido.

Os dados estão na pasta [`data/`](data/). Use-os como quiser: importe para um banco, sirva como
API, transforme. Os campos falam por si; o que não estiver explícito fica a seu critério.

## Regras

- Stack obrigatória:
    - back-end em **PHP com Laravel**;
    - front-end em **Vue** ou **React**, com ou sem framework (ex.: Next.js, Nuxt).
- Arquitetura, bibliotecas e banco de dados são escolha sua.
- **O uso de IA é permitido e esperado.**
- Prazo: **4 dias corridos** a partir do dia seguinte ao recebimento.

## Entregáveis

1. Repositório Git com o código e o histórico de commits.
2. Uma apresentação de cerca de 40min, com o projeto **rodando na sua máquina** e tela
   compartilhada.

## O que será avaliado

- As decisões técnicas e de produto, e como você as justifica.
- O funcionamento e a usabilidade das telas.
- Sua capacidade de explicar e evoluir o que construiu.
